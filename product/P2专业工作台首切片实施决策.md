# P2 专业工作台首切片实施决策

> 决策日期：2026-09-12
> 确认方式：用户授权 WP0/WP1/WP2 自主开发并允许中间采用推荐项
> 实施范围：科研项目工作台与 AI 应用实验室首版

## 1. 最终决定

| 编号 | 采用方案 | 结果 |
|---|---|---|
| P2D-1 | 专业工作台是 Project 的专业视图，不创建第二套项目、任务或来源真源 | 已采用 |
| P2D-2 | 首切片只实现已确认优先级最高的博士科研与 AI 应用探索模板 | 已采用 |
| P2D-3 | 使用明确领域表，不使用任意 JSON 字段承载核心状态 | 已采用 |
| P2D-4 | 研究主张必须绑定固定 SourceVersion、Document、字符范围和 SHA-256 | 已采用 |
| P2D-5 | Claim 的证据方向和强度是用户明确记录，不声称由模型完成蕴含或事实核验 | 已采用 |
| P2D-6 | 研究实验和 AI 评测都记录显式 Continue/Stop 或 Go/Stop 决定 | 已采用 |
| P2D-7 | 形成结果时可在同一事务创建一个回链原 Project 的后续 Task | 已采用 |
| P2D-8 | 所有更新使用版本门、幂等键、权限检查、审计和 Outbox | 已采用 |
| P2D-9 | 首版只处理人工输入和受控本地来源，不调用模型、外部抓取或真实平台 | 已采用 |
| P2D-10 | 不新增生产依赖；复用 React、Fastify、Zod 和 SQLite 基线 | 已采用 |

## 2. 领域对象

- `research_questions`：问题、假设、成功标准和验证状态；
- `research_experiments`：方法、变量、预期、结果、Continue/Stop 和可选后续任务；
- `research_claims`：用户主张、证据方向/强度及不可变来源定位；
- `ai_opportunities`：问题、目标用户、价值/可行性假设和探索状态；
- `ai_experiments`：评测方法、指标、基线、目标、实测结果和 Go/Stop。

以上对象都通过 `space_id + project_id` 回到既有权限和项目真源。来源证据失效时，研究主张保留为历史记录，但读取投影标记 `evidence_integrity=invalid`，不得继续显示为有效证据。

## 3. 页面边界

正式路由为 `/professional`。页面只列出 `research` 和 `ai_exploration` 模板项目，并提供：

1. 研究问题—实验—结果—Claim/Evidence；
2. AI 机会—指标评测—实测—Go/Stop；
3. 可选后续任务回链；
4. 桌面和移动响应式界面；
5. 明示“本地首版、不调用外部模型、不自动写入知识真源”。

## 4. 明确不在本切片

- 文献元数据抓取、PDF/OCR/音频解析；
- 开放式生成、通用 NLI 或事实核验；
- 自动实验执行或模型调用；
- 前沿雷达、学习提升、飞书连接器；
- Harness/Hermes 接入；
- 真实个人、公司或平台数据。

## 5. 验收

- 正常、校验失败、错误模板、版本冲突、越权/无会话、重复请求和重启恢复测试通过；
- Claim 只能使用当前授权项目或空间级受控来源，读取时重新校验精确版本、范围和哈希；
- 结果与后续任务原子提交，重放不产生重复任务；
- 桌面和 390px 页面完成端到端走查；
- 完整测试、构建、隐私扫描及 CI 作为最终交付门。
