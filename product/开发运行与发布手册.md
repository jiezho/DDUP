# DDUP 开发运行与发布手册

> 版本：V1.0
> 日期：2026-08-26
> 状态：开发与本地试运行基线；不是生产发布批准
> 数据边界：默认仅使用仓库中的明确虚构数据

## 1. 标准本地运行

环境要求为 Node.js `>=24.15.0 <25` 与 npm。服务必须只监听本机回环地址。

```text
cd person_dashboard-main/Workbench
npm install
npm run dev
```

默认试运行地址为 `http://127.0.0.1:5173/`。独立本地 API 使用 `npm run start:local-api`，默认地址为 `http://127.0.0.1:8787/`。不得为方便访问改成 `0.0.0.0`、局域网地址或公网监听。

## 2. 发布前验证

每次影响 Workbench 的交付至少执行：

```text
npm test
npm run build
npm run privacy:scan
```

页面/交互变化还需打开实际页面走查关键流程；数据模型、权限、检索和 Runtime 变化需覆盖正常、错误、越权、重复与恢复。失败、跳过或环境限制必须如实记录，不能写成通过。

## 3. 受保护混合检索实验

### 3.1 默认边界

- 未设置变量时 `WORKBENCH_HYBRID_SEARCH_MODE=disabled`，正式行为为 FTS5；
- 只允许固定模型 `BAAI/bge-m3`、revision `5617a9f61b028005a4858fdac845db406aefb181`、CPU 与 `127.0.0.1`；
- 模型与 Python 环境位于仓库外，不属于 npm 生产依赖；
- 只允许明确虚构数据；真实资料、reranker、生成式回答和远程服务不在授权范围。

### 3.2 实验变量

```text
WORKBENCH_HYBRID_SEARCH_MODE=experimental
WORKBENCH_DENSE_SIDECAR_URL=http://127.0.0.1:<本地端口>/
WORKBENCH_DENSE_SIDECAR_TOKEN=<本次启动生成的32至256字符随机值>
WORKBENCH_DENSE_MIN_SCORE=0.50
```

token 只存在于当前进程环境，不写仓库、日志、截图或报告。sidecar 使用 `scripts/run-bge-m3-sidecar.py --model-root <仓库外固定模型目录> --port <本地端口>` 启动；应用与 sidecar 必须使用同一临时 token。结束实验后停止 sidecar 并清除这些变量。

`0.50` 来自 2026-08-26 冻结合成校准集；独立合成盲测的最小相关分与最大无答案 Top-1 分仅相差约 `0.0112`。因此该值只适用于默认关闭的实验模式，不能外推到真实资料或作为回答置信度。

### 3.3 冒烟验证

仅在 sidecar 已启动并设置同一 URL/token 时运行：

```text
npm run smoke:dense-sidecar -- <证据输出路径>
```

脚本只发送两条明确虚构候选，检查未授权 401、固定模型身份和排序结果。它不测试真实资料、不生成回答，也不代表生产启用。

### 3.4 边界与短时诊断

边界评测要求显式传入已审查的仓库外 Python、固定模型目录和证据输出路径：

```text
npm run eval:retrieval-boundary -- --python <隔离Python> --model-root <固定模型目录> --output <证据输出路径>
```

sidecar 已启动并配置同一 URL/token 后，可运行：

```text
npm run bench:dense-sidecar -- <证据输出路径>
```

两个脚本只接受冻结的虚构数据。当前边界门和短时稳定性门均失败；benchmark 可能持续数分钟，必须保持回环访问，并在结束或失败后停止 sidecar、清除 token、确认端口释放。不得把健康接口仍可响应解释为排序服务稳定。

## 4. 故障与回退

- sidecar 未启动、超时、身份不符或响应非法：当前请求自动回退 FTS；
- 无合格 dense 证据：返回 FTS，不把最近邻包装成证据；
- 危险检索意图：在 FTS/dense 前拒绝，不返回对象或范围存在性；
- 实验异常持续：将模式恢复为 `disabled` 并停止 sidecar，业务数据库和 FTS 无需迁移；
- 当前已观测到重复调用超时：诊断完成前不得把 `experimental` 设为常规启动配置；
- 不得通过降低授权过滤、关闭身份检查或把端口暴露到非回环地址绕过故障。

## 5. 当前发布阻塞

本手册不构成发布批准。BGE-M3 边界与短时稳定性门已失败；旧版 `xlsx@0.18.5` 安全处置、完整备份恢复演练、Linux/CI 证据、性能预算、正式发布清单及 G8 仍未完成。在这些门通过前只用于本地开发、研究和合成演示。
