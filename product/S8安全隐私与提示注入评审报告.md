# S8 安全、隐私与提示注入评审报告

> 版本：V0.1
> 日期：2026-09-14
> 状态：自动安全基线通过；人工威胁复核与真实分发环境评审待完成

## 1. 当前结论

默认本地轻量模式未发现已知高危越权、密钥泄漏或静默外部写入。当前证据足以继续本地候选版开发，不足以批准真实飞书、真实私有数据或长期发布。

## 2. 已验证控制

| 风险 | 当前控制 | 证据 |
|---|---|---|
| 非回环 Host | Host allowlist，`trustProxy=false` | 不可信 Host 被拒绝测试 |
| CSRF/跨站写入 | SameSite 会话、Origin、JSON Content-Type、CSRF | 跨站及表单写入拒绝测试 |
| 会话重放 | Bootstrap 单次使用、会话撤销 | bootstrap/revoke 测试 |
| 跨 Space 越权 | 先解析 Principal/Space，再检索或写入 | 项目、检索、Context、Runtime 越权测试 |
| 路径穿越/符号链接 | Vault allowlist、规范化路径、symlink/junction 拒绝 | Reader、XLSX、材料、备份专项测试 |
| Prompt Injection | 固定证据范围预扫描，危险指令失败关闭且不回显正文 | evidence safety、AnswerAttempt 测试 |
| 伪造引用 | SourceVersion、字符范围、SHA-256 和读取时完整性复核 | Citation/Answer/Research/Radar 测试 |
| AI 静默写入 | Candidate → Approval → Apply/Undo；Runtime 不直连业务存储 | Tool Gateway 专项测试 |
| 重复请求 | Idempotency key、scope digest、对象版本 | 项目、任务、候选、卡片未来契约共用 |
| 备份投毒/半恢复 | Manifest 白名单、摘要、regular file、暂存、quick_check、原子落盘 | `backup-recovery.test.mjs` 3/3 |
| 隐私数据入库 | 公共仓库边界、合成数据、隐私扫描 | 2026-09-14 privacy scan 通过 |
| 生产依赖漏洞 | 锁定安装并执行 high 级生产依赖审计 | `c0159cb` 当前 CI 的 Linux/Windows verify Job 通过 |

## 4. 尚未关闭的风险

- 尚未对正式分发包、安装器、自动更新和系统凭据存储做威胁建模。
- 飞书签名、重放、身份映射、卡片动作和撤销仍是设计态，真实平台未授权。
- 未执行真实或脱敏代表性语料的长时间 Prompt Injection 红队。
- 混合检索仍是默认关闭的实验能力；外部模型/OCR/音频没有生产授权。
- 尚未形成 SBOM、完整许可证清单和分发物料哈希。
- 构建大分块可能扩大加载和供应链审查面，需在 G8 前处理或接受。
