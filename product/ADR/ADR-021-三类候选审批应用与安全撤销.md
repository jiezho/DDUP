# ADR-021：三类候选审批、应用与安全撤销

- 状态：已接受
- 日期：2026-09-08
- 扩展：ADR-016

## 决定

Task、Knowledge 和 Decision 共用 Candidate → L2 Approval → Apply 状态机。候选创建是 L1 且不写业务真源；Knowledge Candidate 还必须逐条引用本次 ContextPackage 中完全一致的 Document/SourceVersion/字符范围。审批摘要绑定候选类型、项目和 proposal digest。

应用后记录目标对象 ID 与版本。只有目标仍处于该版本、未删除且没有受保护的后续关系时，Workbench 才允许软撤销；否则明确拒绝，不做级联删除。UI 展示字段级创建预览、策略摘要与低敏审计元数据，不展示正文、凭据或存储路径。

## 退出方式

新增 Tool 必须先定义动作等级、Schema、权限范围、幂等和补偿策略；高风险或外部动作不得复用本地低风险撤销规则。
