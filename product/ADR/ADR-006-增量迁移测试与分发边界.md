# ADR-006：增量迁移、测试和分发边界

> 状态：已接受  
> 决策日期：2026-08-24  
> 对应 G2：A12、A14、A15

## 背景

当前原型功能丰富但生产边界尚未完成。一次性重写会扩大回归面；已有许可表述也尚未统一，不宜直接对外分发新的制品。

## 决定

- 采用绞杀式迁移，先完成“项目—知识—讨论—决策—任务—复盘”端到端垂直切片。
- 保留 Node Test，新增 Playwright 开发测试依赖，覆盖 PC、移动断点、键盘和真实浏览器闭环。
- Windows 与 Linux 均进入 CI；符号链接安全测试至少在 Linux 执行。
- 每个正式功能接管后删除对应重复原型路径，避免长期双轨。
- 许可证统一前只进行本地内部开发与合成数据演示，不发布新的公开制品。

## 后果

每个阶段都可验证和回退，但需要维护短期兼容层，并严格区分原型演示、已实现、POC 候选和生产可用能力。Playwright 会增加开发下载与 CI 缓存成本。

## 回退与复核

若垂直切片不能保持旧页面可用，停止扩展范围，先修复迁移边界。任何外部分发、真实数据试运行或许可证变化都需要单独确认和发布评审。
