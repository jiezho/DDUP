# ADR-004：REST/SSE 与本地安全边界

> 状态：已接受  
> 决策日期：2026-08-24  
> 对应 G2：A9、A10、A11

## 背景

产品首版是本机单用户，但恶意网页、路径穿越、越权检索和重复写入仍可能影响本地服务。本地回环不是完整鉴权；同时 Agent 运行和导入任务需要渐进事件流。

## 决定

- 对象查询与命令使用 REST JSON；长任务事件使用 SSE。
- 输入输出由 Zod 契约校验；写命令支持幂等键和乐观版本。
- 服务仅监听 `127.0.0.1`，使用启动会话、Origin、Content-Type 和 CSRF/nonce 校验。
- 策略默认拒绝，读取、搜索和 Tool Gateway 对每个对象与动作独立鉴权。
- 文件能力只接受受控对象 ID/相对路径，并执行 realpath、根目录与符号链接逃逸检查。
- 首版不提供公网或局域网监听开关。

## 后果

本地攻击面和重复执行风险下降，但客户端启动、Cookie/令牌、SSE 重连和错误返回需要统一协议；安全测试不能只覆盖登录态成功路径。

## 回退与复核

未来远程或多人访问必须重新评估 TLS、身份、设备、凭据、撤销与租户隔离，另立 ADR。不能把 `host` 改为 `0.0.0.0` 作为上线方案。
