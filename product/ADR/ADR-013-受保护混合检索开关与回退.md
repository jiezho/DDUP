# ADR-013：受保护混合检索开关与回退

> 状态：已接受
> 日期：2026-08-26
> 决策来源：G5b-1–G5b-7 全部采用推荐项
> 相关：ADR-003、ADR-011、ADR-012

## 背景

BGE-M3 在固定合成题集上显著优于 FTS，但未经保护的 dense/RRF 会为对抗意图和无答案查询返回近邻。Workbench 需要验证语义召回的工程价值，同时不能让模型获得未授权正文、替换稳定全文基线，或被误认为已经具备引用回答能力。

## 决定

1. FTS5 继续作为默认、对照和自动回退；混合检索只能由 `WORKBENCH_HYBRID_SEARCH_MODE=experimental` 显式启用。
2. 会话与空间/项目授权先于意图判断、FTS、候选正文读取和任何 embedding；sidecar 只能收到已授权 Document 的有界正文。
3. 危险意图在两路召回前确定性拒绝；未知、重复和低于证据阈值的 dense 项不进入 RRF。
4. BGE-M3 保留在仓库外 CPU sidecar。sidecar 固定监听 `127.0.0.1`、使用 bearer token、只提供健康与排序接口；Workbench 校验固定模型 ID/revision、CPU、超时、响应大小和分值。
5. sidecar 不可用、身份不符、超时、响应非法或无合格 dense 证据时，当前请求回退 FTS；故障不形成粘性状态，后续请求可恢复。
6. 混合结果只影响只读排序，不写 Project、Source、Document、Knowledge 或向量真源；生成式回答保持关闭。
7. 不新增 Workbench 生产依赖，不下载 reranker，不接真实资料。默认启用、真实数据接入、生产打包或生成式引用问答均需后续独立决定。

## 后果

- 得到可撤销、可测的语义召回路径，模型故障不会阻塞本地全文检索。
- 每次实验需单独启动约 1.9 GiB 峰值工作集的仓库外进程，并提供短期 token；这不是免运维的正式能力。
- 固定阈值 `0.72` 只由现有合成证据支持，独立盲测和校准完成前不得默认启用。
- 生成式回答不能以“检索已接通”为理由自动进入范围。

## 回退与退出

删除或关闭实验环境变量即可回到纯 FTS，不迁移或删除业务真源。sidecar、模型环境和实验证据可以独立移除；若后续盲测、性能、安全或许可门失败，撤销实验入口而不改变 API 的 FTS 行为。

## 验证证据

- `tests/protected-hybrid-search.test.mjs`：正常、越权、拒绝、低置信度、故障、恢复、重复和回环适配约束；
- `product/evidence/BGE-M3-protected-sidecar-smoke.json`：token/模型身份和两条虚构候选的真实 sidecar 冒烟；
- `product/AI评测方案与检索评测报告.md`：条件式 Go 与剩余安全门。
