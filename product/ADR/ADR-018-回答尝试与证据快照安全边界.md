# ADR-018：回答尝试、证据快照与生成安全边界

> 状态：已接受
> 日期：2026-09-01
> 关联：ADR-008、ADR-009、ADR-012、ADR-014；S4-04

## 背景

ContextPackage 已能在读取时派生固定 SourceVersion 的 Citation Manifest，但直接把“证据准备完成”写成 Answer 会制造并不存在的回答真源；直接进入模型又会越过无证据拒答、提示注入、泄漏和逐句蕴含安全门。系统需要先证明问题、上下文版本、拒答原因和证据引用可以稳定持久化、重放和审计。

## 决定

1. migration 011 新增 `answer_attempts` 与 `answer_attempt_citations`，明确它们是回答前安全检查记录，不是最终 Answer/Citation 或长期知识。
2. 创建 AnswerAttempt 时重新解析当前会话可访问的 ContextPackage，并要求客户端观察到的包版本完全一致；过期、归档、版本变化和不可访问空间全部失败关闭。
3. 问题先经过确定性危险意图检查。危险意图保存 `refused_unsafe_intent`，无固定原文证据保存 `refused_no_citable_evidence`；两者都不保存引用快照、不进入模型或 Runtime。
4. 只有有效 Document Citation 才能保存为 AnswerAttempt 的证据快照，字段固定到 Source、SourceVersion、Document、字符范围和正文 SHA-256；不复制 quote、Document 正文或业务对象正文。
5. 有证据时只保存 `evidence_ready`。`generation_enabled` 在数据库约束、API 和 UI 中恒为 `false`，记录中不存在 answer text 字段。
6. 创建命令使用 Idempotency-Key，并与 AnswerAttempt、AuditEvent 和 OutboxEvent 在同一事务提交；重复请求不产生重复记录。
7. 列表、单条读取和幂等重放都必须按固定的 Source、SourceVersion、Document、字符范围和 SHA-256 重新复核证据。来源不可用、范围失效或哈希不一致时返回当前 `integrity=invalid`，后续生成必须失败关闭；历史 AnswerAttempt 状态和审计事实不被悄悄改写。
8. 创建 AnswerAttempt 时只扫描用户明确选入的固定原文范围，确定性识别指令覆盖、角色冒充、敏感信息索取和外部外泄模式。命中后以 `UNSAFE_EVIDENCE_*` 原因码记录拒答，不保存引用快照、不回显命中片段、不扫描未选入范围，也不进入模型或 Runtime。
9. 每次返回 AnswerAttempt 时派生 `generation_gate`：既有拒答优先为 `blocked_refusal`，引用未验证为 `blocked_integrity`，只有安全与完整性均通过时才报告 `blocked_model_unavailable`。当前没有获准的回答 Runtime/Profile，因此 `available=false` 且标识均为空；该投影不执行健康探测、不创建 Run，也不新增写入。

## 结果

- 回答前安全状态可以跨重启复核，引用范围不会随 ContextPackage 后续变化而漂移；
- 拒答成为可审计事实，不再只是 UI 提示；
- 项目、任务和捕获仍不能伪装成原文 Citation；
- 引用快照不仅可重放，还能在来源或定位异常时显式暴露 `source_unavailable/range_invalid/hash_mismatch`，而不是沿用过期的“证据就绪”判断；
- 授权可见不再自动等于可供模型消费：被选中的来源范围仍需通过确定性证据安全检查；
- 模型不可用不再只是页面文案，而是稳定的机器可读失败关闭状态；同时不会把 Native 确定性 Runtime 或未连接候选误报为回答运行时；
- 当前能力不生成答案、不证明逐句蕴含，也不授权模型、外部服务或最终 Answer/Citation 真源。

## 退出与演进

只有提示注入/泄漏、模型不可用回退、逐句蕴含和最终引用定位测试全部达到独立安全门后，才可另行设计 Answer/Citation 真源和生成服务。届时 Answer 必须引用本次固定的证据快照或建立等价的不可变证据链，不得把 `evidence_ready` 原地改写为“已回答”。

## 证据

- migration 011：`answer_attempts`、`answer_attempt_citations`；
- `/api/v1/context/answer-attempts` 创建、列表与读取契约；
- 正常、无证据、危险问题、来源提示注入/外泄、版本冲突、过期、不可访问空间、幂等、重启恢复及来源漂移失败关闭测试；
- 上下文库桌面端/390px“回答安全检查”交互与合成截图。
