# ADR-014：显式上下文篮与解析时再授权

> 状态：已接受
> 日期：2026-08-27

## 背景

个人上下文知识库在逻辑上可发现全部授权内容，但一次分析或 Runtime 不应默认读取全库。范围还需要在对象删除、来源换版、权限收紧、包过期或归档后继续安全。

## 决定

1. ContextPackage 从空的显式 allowlist 开始，必须包含名称和明确用途，可选有效期。
2. Project、Task 和 Capture 只保存对象引用；Document 必须锁定 SourceVersion 及字符起止。包项不复制 title、quote 或 body。
3. 每次读取包时重新校验空间可见性、对象存在性、SourceVersion 和字符范围。失效项返回稳定排除原因，不返回正文。
4. 过期和归档包可保留元数据与审计历史，但不向后续运行提供正文。
5. 创建、加入、移除和归档使用幂等键；修改使用 `If-Match` 乐观版本，与 AuditEvent/OutboxEvent 在同一事务提交。
6. 本切片不启动模型、不生成回答，只为后续 Answer/Runtime 提供可解释的范围候选。

## 后果

- 优点：范围最小、可审计、无正文副本，来源或权限变化可在使用前生效。
- 代价：包详情需要读取时解析；项目名称变化会展示当前值，不是创建时快照。
- 限制：当前只支持四类对象，没有默认范围推导、动态查询规则或 Runtime 绑定。

## 退出与演进

未来若需要动态规则，另增版本化 ScopeRule，但仍在解析时先授权。若需要可复现的历史回答，由 Run/Citation 固定当次已授权的 SourceVersion 和引用，不把 ContextPackage 扩展为正文仓库。
