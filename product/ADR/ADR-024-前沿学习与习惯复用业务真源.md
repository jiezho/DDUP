# ADR-024：前沿、学习与习惯复用业务真源

> 状态：已接受
> 日期：2026-09-12

## 背景

前沿雷达、学习提升和习惯需要专业状态，但如果复制项目、任务、来源或今日计划，会造成多个真源。前沿转述还必须与固定来源证据分离；学习结果也不能由系统伪造。

## 决定

1. 使用 migration 015 的明确领域表保存前沿专题/信号、学习方向/练习和轻量习惯/打卡。
2. 所有对象以 `space_id + project_id` 复用既有权限和 Project 真源；可执行行动仍回到既有 Task。
3. 前沿信号固定到 SourceVersion、Document、字符范围和服务端 SHA-256，并显式标记事实/转述/观点/推断。
4. 学习只保存用户明确记录的目标、基线、练习、反思、反馈、自评和决定；不声称模型评价。
5. 习惯打卡以 `routine_id + local_date` 唯一，防止重放或重复日期产生双写。
6. 首版完全本地、人工录入，不抓取、不通知、不调用外部模型。

## 后果

- 三个工作包获得可恢复、权限感知和可审计的垂直闭环；
- 专业页面关闭时，核心 Project、Task、Source、Today 和 Context 真源不受影响；
- 在线订阅、自动聚类、音频和平台连接器仍需各自确认门。

## 回退

关闭 `/growth` 导航与路由即可停止 UI；migration 015 保留历史表，不执行破坏性降级。核心项目、检索和运行时不依赖这些表。
