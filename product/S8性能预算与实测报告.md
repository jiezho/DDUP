# S8 性能预算与实测报告

> 版本：V1.0
> 日期：2026-09-14
> 状态：本地轻量模式首轮通过；分发包、长时间运行和混合检索预算未完成

## 1. 预算

| 指标 | 首轮门槛 |
|---|---:|
| 服务和迁移就绪 | ≤ 5,000 ms |
| 健康检查 p95 | ≤ 100 ms |
| 项目列表 p95 | ≤ 300 ms |
| FTS 检索 p95 | ≤ 500 ms |
| 普通项目写入 p95 | ≤ 500 ms |
| 默认进程 RSS | ≤ 1,024 MiB |

该预算用于本地优先的默认轻量模式。BGE-M3 sidecar、OCR、音频和外部模型使用独立预算，不能用本结果描述为生产可用。

## 2. 可复现方法

- 命令：`npm run bench:release`
- Runtime：Node v24.19.0，Windows x64。
- 全部数据为运行时创建并删除的虚构数据。
- 数据量：230 个项目、100 篇 Markdown 文档。
- 健康检查、项目列表和 FTS 各测量 100 次；项目创建测量 30 次。
- 使用 Fastify 本地注入衡量服务处理时间，不包含浏览器网络、磁盘冷启动和分发包启动器开销。

## 4. 尚未关闭的预算项

- 浏览器冷启动、首屏可交互和弱网条件尚未进入同一份自动预算。
- 10 万对象/100 万关系门已有 SQLite CI 证据，但尚未在真实业务 Schema 上测量 UI/API p95。
- 生产构建仍有大于 500 kB 的分块警告，需要拆包或在 G8 明确接受。
- 分发包首次启动、跨设备恢复、连续七天内存趋势尚未测量。
- 本结果不能代表真实私有数据、外部连接器或模型调用成本。
