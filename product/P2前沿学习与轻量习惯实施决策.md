# P2 前沿、学习与轻量习惯实施决策

> 决策日期：2026-09-12
> 确认方式：用户授权继续自主完成 WP3/WP4/WP5，并沿用此前“中间自行确认”方式
> 实施范围：前沿雷达、通用学习/学术英语、轻量计划与习惯首版

## 1. 最终决定

| 编号 | 采用方案 | 结果 |
|---|---|---|
| P2G-1 | WP3 对应 S6-03 前沿雷达；WP4 对应 S6-04/05 通用学习与学术英语；WP5 对应 S6-06 轻量计划/习惯及本地交付收口 | 已采用 |
| P2G-2 | 三个工作包继续复用 Project、Task、Source、权限、审计和 Outbox 真源 | 已采用 |
| P2G-3 | 前沿首版只接受人工录入和已受控本地 Source，不做抓取、订阅或自动周报 | 已采用 |
| P2G-4 | 每条前沿信号强制标记一手事实、二手转述、观点或人工推断，并绑定固定 SourceVersion、Document、字符范围和 SHA-256 | 已采用 |
| P2G-5 | 前沿专题显式记录成熟度、限制、影响、关注/验证/忽略决定和复查日期 | 已采用 |
| P2G-6 | 学习方向使用通用 Track→Practice→Reflection/Feedback→Decision 闭环，英语只是内置类别和 focus，不复制底座 | 已采用 |
| P2G-7 | 英语首版覆盖学术阅读、学术写作和日常口语文本练习；不保存音频、不做发音评分 | 已采用 |
| P2G-8 | 轻量习惯只记录周期、目标次数和按本地日期的打卡；项目行动仍必须使用既有 Task | 已采用 |
| P2G-9 | 复核和练习结果可在同一事务创建一个回链原 Project 的后续 Task | 已采用 |
| P2G-10 | 不新增生产依赖、不接真实平台、不调用外部模型；所有测试数据保持明确虚构 | 已采用 |

## 2. 实现边界

正式路由为 `/growth`。migration 015 提供 `radar_topics`、`radar_signals`、`learning_tracks`、`learning_practices`、`learning_routines` 和 `learning_checkins`。写操作继续要求本地 Session、同源 CSRF、幂等键；现有对象复核要求 `If-Match`。证据失效时保留历史信号并标记 `evidence_integrity=invalid`。

## 3. 明确不在本切片

- 在线资讯抓取、RSS/邮件订阅、自动聚类或自动周报；
- AI 自动总结、事实判断、知识写入或学习评分；
- 音频、发音分析、语音服务或真实学习数据；
- 飞书、Hermes/Harness、外部消息和定时通知；
- G8 正式发布决定。

## 4. 验收

- 正常、错误模板、缺少版本、重复请求、重复日期、无会话、来源归档和重启恢复通过；
- 前沿信号的固定证据每次读取重新校验；
- 复核/练习结果与可选后续任务保持原子、幂等和可审计；
- 桌面与 390px 页面完成关键流程走查；
- 完整测试、生产构建、隐私扫描和 Git 变更边界通过。
