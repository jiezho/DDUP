# DDUP 设计系统（v1）

## 0. 参考样本与定位

### 0.1 主参考：Adaline（用户提供截图）
- 设计语言关键词：自然、安静、留白、柔和渐变、低饱和绿色点缀、圆角胶囊按钮、信息密度适中。
- 适配 DDUP：用于“工作台/对话/学习/资源/我的”这类高频操作型产品时，需要在保持柔和感的同时，补强信息密度与可读性（表格/列表/卡片状态层级更清晰）。

### 0.2 次参考（用于规则校准）
- Ant Design 5 Token 体系：用于与现有技术栈一致的组件规范与状态表达。
- Material 3 / Apple HIG（可访问性与动态）：用于补齐动效、焦点、可达性标准与布局断点方法。

## 1. 设计语言拆解

### 1.1 色彩体系
- 核心策略：以“暖中性背景 + 绿色主色”形成温和、可信的产品气质；用高对比中性色保障文本可读；状态色严格限定使用场景。
- 背景：自上而下的轻柔渐变，减少纯白刺眼与大面积灰的冷感。
- 主色：用于主 CTA、选中态、进度与强调信息。
- 中性色：用于文本层级、边框、分割线与禁用态。
- 状态色：成功/警告/危险只用于结果与风险提示，不参与品牌表达。

#### 色板（推荐）
- Primary
  - Primary 600：#136447（hover/active 强调）
  - Primary 500：#1B7F5A（主 CTA、选中）
  - Primary 100：rgba(27,127,90,0.12)（轻提示背景/Tag/选中底）
- Neutral
  - N950：#0F172A（主正文）
  - N800：#1F2937（次正文/标题）
  - N600：#4B5563（说明文字）
  - N400：#9CA3AF（弱化/禁用文字）
  - N200：#E5E7EB（分割/边框）
  - N50：#F8FAFC（浅底）
- Semantic
  - Success：#16A34A
  - Warning：#D97706
  - Danger：#DC2626

### 1.2 字体规范
- 字体栈：系统字体优先（性能与一致性），等宽字体仅用于 ID/路径/代码。
- 字号/行高层级（桌面为基准）
  - Display：32 / 40，字重 700（页面主标题少量使用）
  - H1：24 / 32，字重 700
  - H2：18 / 28，字重 600
  - Body：14 / 22，字重 400（默认正文）
  - Meta：12 / 18，字重 400（说明/辅助）

### 1.3 间距与栅格
- 采用 4pt 基准：4/8/12/16/20/24/32/40/48。
- 页面外边距：Desktop 24；Tablet 16；Mobile 12。
- 卡片内边距：Desktop 16；Mobile 12。
- 列表项高度：Dense 44；Default 52。

### 1.4 圆角/阴影
- 圆角
  - 控件：12（输入框/按钮）
  - 卡片：16（Card/Drawer/Modal 容器）
  - 胶囊：999（强 CTA、筛选 Chip）
- 阴影（只在 hover/focus 或浮层使用）
  - Shadow 1：轻浮起（默认）
  - Shadow 2：卡片 hover（强调）

### 1.5 动效
- 基础缓动：cubic-bezier(0.22, 1, 0.36, 1)
- 时长
  - 120ms：按钮按压/轻反馈
  - 160ms：hover/阴影变化
  - 220ms：抽屉/弹窗进入

## 2. 组件规范（原子化）

### 2.1 原子（Atoms）
- Button：主/次/危险；默认胶囊；明确 hover/active/disabled/loading 状态。
- Input：单行、文本域；一致圆角与 focus ring；错误态边框+提示文案。
- Tag/Badge：仅作分类与状态提示，不作为主要交互按钮。

### 2.2 分子（Molecules）
- SearchBar：Input + Button/快捷筛选。
- ListItem：标题/摘要/右侧操作区；支持密度切换。
- EmptyState：图标/标题/说明/主 CTA。

### 2.3 组织（Organisms）
- PageShell：顶部/侧边/底部导航的统一布局；桌面与移动端样式统一但布局不同。
- DataTable：分页/排序/空态/加载态；行 hover 与选中态统一。
- DetailDrawer：详情抽屉（标题、操作区、内容区、底部确认）。

## 3. 响应式断点规则
- Mobile：< 768
- Tablet：768–1199
- Desktop：≥ 1200

规则：
- Desktop：多列布局（工作台、资源管理），允许侧栏。
- Tablet：保持桌面信息结构，但减少边距与列数（2 列 → 1 列）。
- Mobile：单列与底部导航优先；操作按钮不堆叠为长文本，优先图标+短词。

## 4. 可访问性（WCAG 2.1）

### 4.1 对比度
- 正文文本：≥ 4.5:1
- 大号文本（≥ 18pt 或 14pt bold）：≥ 3:1
- 图标与非文本控件：≥ 3:1（尤其是边框与焦点环）

### 4.2 焦点与键盘
- 全局 focus-visible：统一焦点环（3px 半透明主色），不依赖阴影。
- 可交互元素必须可 Tab 到达；抽屉/弹窗需焦点陷阱（AntD 默认具备）。

### 4.3 反馈与状态
- 错误信息需文本+颜色双通道；不要只用红色表达。
- Loading 必须可感知（按钮 loading 或骨架屏），并避免布局跳动。
