# DDUP UI 走查清单与验收标准（v1）

## 1. 像素级还原验收
- 字体：字号/行高/字重与规范一致；不同页面不出现同层级不同字号。
- 间距：页面边距、卡片 padding、列表项间距符合 4pt 体系；不出现 13/15/19 等“非体系”间距。
- 圆角：控件 12、卡片 16、胶囊 999；同类组件保持一致。
- 阴影：仅 hover/浮层使用；默认状态不滥用阴影。
- 颜色：主色与状态色不混用；文本层级只使用 text-1/2/3。

## 2. 组件一致性
- Button
  - 主按钮只用于关键路径主 CTA，每屏≤1 个主按钮优先。
  - disabled/hover/active/loading 状态一致。
- Input
  - focus ring 可见且不被遮挡；错误态提示与边框一致。
- Card/List/Table
  - hover 反馈一致；空态/加载态一致。
- Navigation
  - 当前选中态明确；在三端布局中位置一致（桌面侧栏/移动底栏）。

## 3. 响应式走查
- Desktop（≥1200）
  - 列表/工作台多列布局正确；内容区最大宽度与阅读舒适度合理。
- Tablet（768–1199）
  - 栅格降列；操作区不溢出；抽屉宽度适中。
- Mobile（<768）
  - 单列布局；触控区域≥44px；底部导航不遮挡输入框。

## 4. 可访问性走查（WCAG 2.1）
- 对比度：正文≥4.5:1，大字≥3:1，控件边框/图标≥3:1。
- 键盘：Tab 顺序合理；焦点可见；抽屉/弹窗可关闭并返回触发点。
- 可读性：错误提示不只靠颜色；图标按钮具备可读 label（aria-label）。

## 5. 交互与动效
- 动效时长与缓动一致（120/160/220ms + 统一 ease）。
- 关键操作有即时反馈；网络慢时有 loading 状态。
- 空态可引导下一步（主 CTA + 说明文案）。
